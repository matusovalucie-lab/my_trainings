# My Trainings v0.5.2

Kompletní statická PWA připravená pro GitHub Pages.

## Datové soubory

- `data/workouts.json` – pevná struktura Workout A/B/C, Hiking a Micro Workout
- `data/areas.json` – názvy, ikony a barvy oblastí
- `data/exercises.json` – české názvy, anglické názvy v závorce, místo, pomůcky, série a opakování
- `data/settings.json` – základní nastavení aplikace

Nahraj celý obsah této složky do kořene repozitáře. Zachovej podsložky `data/` a `icons/`.
