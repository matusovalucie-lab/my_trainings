# My Trainings PWA

Mobilní webová aplikace pro GitHub + Netlify, optimalizovaná pro používání na iPhonu.

## Co funguje

- Workout A
- zápis váhy a opakování
- automatické uložení v Safari
- přeskočení cviku a návrat
- obnovení rozpracovaného tréninku
- dokončení tréninku
- historie
- instalace na plochu
- základní offline režim

## Nasazení přes GitHub a Netlify

### 1. GitHub

1. Vytvoř nový veřejný nebo soukromý repozitář.
2. Nahraj do kořene repozitáře všechny soubory z tohoto balíčku.
3. Zkontroluj, že `index.html` je přímo v kořeni repozitáře, ne v další podsložce.

### 2. Netlify

1. Přihlas se do Netlify.
2. Zvol **Add new project**.
3. Zvol **Import an existing project**.
4. Vyber **GitHub** a povol přístup k repozitáři.
5. Vyber repozitář `my-trainings`.
6. Build command nech prázdný.
7. Publish directory nastav na `.`
8. Zvol **Deploy**.

### 3. Instalace na iPhone

1. Otevři Netlify adresu v Safari.
2. Klepni na Sdílet.
3. Zvol **Přidat na plochu**.
4. Potvrď název My Trainings.

## Důležité

Data jsou zatím uložená pouze v Safari na daném iPhonu. Smazání dat webu nebo používání jiného prohlížeče historii odstraní.
